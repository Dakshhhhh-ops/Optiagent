# OptiAgent

Natural language to **verified** optimization. OptiAgent turns a plain-English planning problem plus
your tabular data into a linear program, solves it, audits the formulation for the mistakes LLMs
actually make, and explains the result and its sensitivities.

**The LLM never produces the final numbers.** It only fills typed structures; numbers come from your
files (loaded by code) or from your text (checked against it), the model is built and solved
deterministically, and you approve the exact formulation before anything is solved.

## How it works

```
Description (+ optional CSV/Excel)
  → Analyze (LLM): problem type, requirements, clarifying questions
  → Extract (LLM): typed problem from text, or a column mapping for uploaded data
      ↳ grounding: every number must appear in your text (retry with feedback if not)
  → Confirm (you): formulation in plain English + math, generated by code
      ↳ audit: values, limits, forbidden pairs and wording cross-checked against your text,
               sanity tests, and an independent LLM review of each requirement
  → Solve (OR-Tools GLOP) → verify (constraints, bounds, objective recomputed)
  → Explain: shadow prices, exact one-unit effects, ranges, unused options, what-if
      ↳ or, if infeasible: the minimum shortfall per destination/task
```

Supported in v1: **transportation** and **assignment** problems.

## Repository layout

```
core/    optiagent_core   – schema, model builder, solver, checks, analysis (HiGHS), ingestion, formulation
agent/   optiagent_agent  – Ollama client, analyze/extract pipeline, grounding, audit, requirement review
api/     optiagent_api    – FastAPI service
eval/    optiagent_eval   – generated + hand-written benchmarks, error injection, runner, report
web/                      – Next.js + TypeScript + Tailwind + shadcn/ui frontend
```

`core` has no LLM or web dependencies, so it can be tested on its own.

## Prerequisites

- [uv](https://docs.astral.sh/uv/) (installs Python 3.12 automatically)
- Node 24 and pnpm
- [Ollama](https://ollama.com) with `qwen3:8b` (`ollama pull qwen3:8b`)
- Docker Desktop (optional: Postgres and Redis, or the whole stack)

## Running locally

```bash
cp .env.example .env

# API → http://localhost:8000/docs
uv sync
uv run uvicorn optiagent_api.main:app --reload

# Web → http://localhost:3000
cd web
pnpm install
pnpm dev
```

If port 8000 is taken, run the API on another port and start the web app with
`NEXT_PUBLIC_API_URL=http://localhost:<port> pnpm dev`.

After changing API models, regenerate the TypeScript types with `pnpm gen:api` (in `web/`).

## Checks

```bash
uv run ruff check . && uv run ruff format --check . && uv run mypy && uv run pytest
cd web && pnpm lint && pnpm typecheck && pnpm build
```

CI runs the same checks on every push.

## Evaluation

```bash
uv run python -m optiagent_eval.mutations                         # audit vs injected errors (no LLM)
uv run python -m optiagent_eval.run --model qwen3:8b --mode full  # also: no-verify, direct
uv run python -m optiagent_eval.report                            # writes eval/REPORT.md
```

Results and caveats are in [eval/REPORT.md](eval/REPORT.md) and on the Benchmarks page.
